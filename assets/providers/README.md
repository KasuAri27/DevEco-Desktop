# Provider logo sources

- Huawei: existing `../huawei.svg`, Simple Icons (CC0). `../huawei-app.png` is a rasterized copy for the native window icon.
- DeepSeek, Qwen, Zhipu, Moonshot: `@lobehub/icons-static-svg` 1.95.1, https://github.com/lobehub/lobe-icons (MIT; accompanying license).
- Xiaomi: https://github.com/simple-icons/simple-icons/blob/develop/icons/xiaomi.svg (CC0).

These assets identify the corresponding providers. Provider brand marks retain their source shapes; custom providers with no known company identity use a generic connector icon.
