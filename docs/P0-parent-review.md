| 范围 | 当前实现 |

## 你怎么审查

先关闭旧的桌面窗口，在项目目录执行：

```powershell
cd "D:\IDE\DevEco Desktop"
npm test
npm start
```

建议按顺序检查：

1. **首次设置 → 环境与诊断**：重新检测版本与路径，确认修改路径后后台实际重启，无需手动开 CLI。
2. **Provider**：先走第三方入口，配置你的提供商与默认模型；不登录华为也应能完成该入口。检查凭据不回显、原生 SDK 保留、自定义 Provider 可编辑／移除／重新添加。
3. **协议与隐私**：查看当前协议，主动决定是否同意；分别检查账号体验改进与两个设备开关，保存后刷新核对。
4. **配置中心**：分别保存一个全局字段和一个项目字段，刷新读回。项目只应写当前工程识别的配置文件，保留已有注释与其他字段。
5. **会话**：切换不同模型，检查档位跟随模型、最高档位动画、无档位时禁用。发送一个你选择的简单任务，检查流式输出与停止，再关闭／重开检查最近会话恢复。
6. **账号与开发者**：如需内置模型，再检查浏览器登录、取消、认证页、重新核验和团队检查。退出登录会真正移除核心账号，只在你打算退出时执行。
7. **故障检查**：授权期间尝试保存设置，应有明确提示；诊断页应显示脱敏错误与重试入口。

详细操作见 [验收清单](P0-review-checklist.md)，接口证据与实现限制见 [子代理实现报告](P0-implementation-report.md)。

**尚未代你验收的内容**：真实账号浏览器往返、实际实名结果、真实提供商对话，以及完整 GUI 的视觉与交互。这些需要你按上述步骤在 Electron 窗口确认；自动测试结果不代表它们已经通过。
